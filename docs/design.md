# Design Notes

Universe Evolution Lab 当前是命令行 MVP。设计目标不是一次性构建完整世界观，而是先把复杂结构、生命分类、文明、事件、分支和观察工具跑通。

## 设计原则

### 初始阶段少设定

当前阶段只保留必要概念：宇宙、复杂结构、Population、物种、文明、事件、模拟配置。命名和事件描述保持简洁，避免过早绑定宏大叙事。

### 只设基础演化机制，不预设文明终点

模拟规则只覆盖基础趋势：

- 无生命复杂结构可能形成、保持、复制、变异、聚合趋势化或瓦解。
- 某些结构可能被分类为 proto_life 或 life_lineage。
- life_lineage 长期保持后可能形成 Population。
- Population 稳定后可能形成物种。
- 物种可能增长、衰退、突变、灭绝。
- 物种满足人口、智能、合作等条件时，可能产生原始文明。
- 文明可能增长、稳定、衰退、冲突或崩溃。

系统不预设文明一定会走向某个终点，也不预设某种模式一定优越。

### 观察优先，干预克制

用户可以创建、推进、查看、分支、导出和比较实验，但没有直接修改物种或文明属性的命令。尤其是 `minimal_observer` 模式，强调低干预观察。

### 模拟规则和叙事展示分离

模拟逻辑集中在 `simulator.py`。报告、统计、导出、对比和批量汇总集中在 reporting 或 batch 相关模块。这样后续可以扩展展示层，而不直接改变演化规则。

### 不加入后期设定

当前不加入：

- 造物主主线
- 外层真实世界感知
- 终极文明
- 预设文明结局
- AI API 叙事生成
- VR 或网页表现层

这些方向可以作为后期扩展讨论，但不进入当前基础模拟层。

## 三种 MVP 模式

### life_burst

复杂性涌现/生命大爆发观察模式。初始生成多个无生命复杂结构，没有初始 Population、物种或文明。重点观察结构在随机扰动和内部属性变化下，是否会被系统识别为 proto_life、life_lineage，并进一步形成 Population、物种和文明。

适合问题：

- 哪些无生命复杂结构能维持复杂性？
- 哪些结构会退化或崩溃？
- 哪些属性组合更接近 proto_life 或 life_lineage？
- 文明是否会自然出现？

### civilization_seeds

文明种子模式。初始生成 3 个原始文明。重点观察文明知识、组织、创造力、稳定、扩张、伦理等因素的演化。

适合问题：

- 文明在早期条件不同的情况下如何分化？
- 哪些文明会增长、衰退或崩溃？
- 文明之间的统计差异如何积累？

### minimal_observer

最小干预观察模式。用户不能直接改变文明或生命属性，只能创建、推进、查看、导出和复制分支。

适合问题：

- 同一个时间点复制分支后会如何分化？
- 少干预观察能否形成稳定的对照实验？
- 哪些事件对长期结果影响更明显？

## 模块边界

- `models.py`：核心 dataclass。
- `modes.py`：三种模式的初始宇宙生成。
- `simulator.py`：每一步演化规则。
- `storage.py`：JSON 存档和分支复制。
- `reporting.py`：单个宇宙的统计、导出、报告和对比。
- `batch.py`：批量运行和批量汇总。
- `main.py`：命令行参数解析和调用分发。

## Complexity Emergence Model

项目不直接设定生命是否产生。`life_burst` 模式从无生命复杂结构开始，而不是直接投放生命种子、物种或文明。

系统只模拟结构在环境中的形成、保持、复制、变异、聚合趋势和瓦解。生命是当某些结构在长期演化中表现出自维持、能量处理、信息保留、复制潜力、边界性和适应性后，由系统识别出的涌现分类。

当前分类路径是：

- `inert`
- `complex_structure`
- `self_maintaining`
- `proto_life`
- `life_lineage`

当 `life_lineage` 长期保持 active，并且复制潜力、适应性、边界性和稳定性足够时，可能形成 Population。Population 稳定增长并积累多样性后，才可能形成 Species。Species 后续沿用现有物种演化逻辑，并可能产生 Civilization。

这意味着：

- 某些宇宙可能永远不产生生命。
- 某些宇宙可能产生准生命但很快瓦解。
- 某些宇宙可能形成生命谱系、族群、物种和文明。
- 文明不会直接从结构产生，只能从 Species 后续演化出现。

当前模型是科学启发的抽象模型，不是精确物理、化学或生物仿真。它用于观察复杂性层级如何在简单规则下变化，而不是预测真实生命起源。
