# Roadmap

Universe Evolution Lab 采用逐步扩展路线。当前优先保证命令行实验闭环稳定，再考虑更复杂的模拟和展示。

## 已完成

- CLI MVP
- 三种模式：
  - `life_burst`
  - `civilization_seeds`
  - `minimal_observer`
- 基础生命和文明演化
- JSON 存档读取和保存
- 分支复制
- 观察工具：
  - `show`
  - `stats`
  - `timeline`
- 导出和报告：
  - `export`
  - `report`
- 分支和宇宙对比：
  - `compare`
- 批量实验：
  - `batch`
  - `summary`
- pytest 测试和 ruff 检查

## 近期下一步

- 实验参数系统：
  - 初始物种数量
  - 初始文明数量
  - 随机事件强度
  - 突变概率范围
- 可复现实验 seed 的更完整 CLI 支持
- 配置文件：
  - JSON 配置
  - TOML 配置，如果仍坚持标准库，则需 Python 3.11+ 的 `tomllib` 只读支持
- 更多统计指标：
  - 灭绝率
  - 文明崩溃率
  - 文明出现时间
  - 平均事件密度
  - 分支分化程度

## 中期

- 文明碰撞：
  - 资源竞争
  - 贸易或冲突
  - 技术传播
- 大过滤器：
  - 生态风险
  - 内部失稳
  - 资源枯竭
- 递归造物模式：
  - 文明创建子模拟
  - 子模拟对文明文化或知识产生反馈
  - 保持可选，不影响基础模式

## 后期

- 简单 Web UI
- AI 叙事增强
- 2D 可视化
- 3D/VR 扩展

这些后期能力不属于当前 CLI MVP。进入这些方向前，需要先稳定模拟规则、存档格式、统计口径和测试覆盖。
