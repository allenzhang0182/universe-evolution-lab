## 4. Prohibited Operations

AI tools **must not** perform the following under any circumstances:

- Modify `.env`, `.env.*`, or any file containing secrets, tokens, or API keys
- Modify production configuration files
- `git push` to any branch without explicit human approval
- `git merge main` or any branch merge without explicit human approval
- Large-scale refactoring not explicitly scoped in the task
- Expand the task scope beyond what is defined in the task description
- Create new files outside the explicitly allowed file path list
- Run destructive commands (`rm -rf`, `git reset --hard`, `git clean -fd`) without confirmation

## 6. Aider Usage Reminders

> Quick-entry checklist before using Aider or any AI execution tool.

### 6.1 Pre-Flight Checklist

- [ ] **Check allowed files** — Confirm the task's `Allowed files` / `Allowed directories` list is defined and understood.
- [ ] **Never add all files automatically** — Reject `all files`, `auto add`, and `don't ask again` prompts from Aider.
- [ ] **Reject suspicious file creation** — If Aider proposes a file with an abnormal name (natural language, `SEARCH/REPLACE`, `Let's`, `Here is`, patch snippets), reject it and stop the task.
- [ ] **Stop if scope expands** — If the tool suggests modifying files outside the allowed scope, stop and escalate to a human.
- [ ] **No auto-commit** — Do not let Aider `git commit` automatically; require human approval.
- [ ] **No auto-push** — Do not let Aider `git push` under any circumstances.

### 6.2 When to Avoid Aider

- **High-risk tasks** — Never delegate authentication, permissions, database schema, production config, or audit tasks to Aider.
- **Unclear file scope** — If the task does not list explicit file paths, use Zoo Code + DeepSeek or ChatGPT for planning first.
- **Multi-file changes** — Aider struggles with 3+ files; use Zoo Code + DeepSeek instead.
